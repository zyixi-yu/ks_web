## Why

当前站点整体观感偏“拼贴”，移动端导航栏拥挤且易换行，影响可用性与专业度。需要统一信息层级与交互范式，让工具型页面在手机与 PC 都更易用、更像一个完整产品。

## What Changes

- 将顶部导航改为“App Bar + 汉堡菜单抽屉（Drawer）”，移动端优先优化，PC 同样使用精简文案与一致的导航入口。
- 统一导航/页面文案：使用短标签化命名（积分/议会/排行/角色/翻译），并精简站点副标题（移动端可隐藏）。
- 优化排行榜“可点击查看详情”的表达：移除每行冗余提示，改为更标准的可点击行范式（例如右侧 chevron + hover/active 反馈 + 单处提示）。

## Capabilities

### New Capabilities

- `web-navigation-drawer`: 提供移动端友好的抽屉式导航与统一的导航文案规范。
- `dashboard-ui-polish`: 统一页面头/卡片壳/列表交互的视觉与体验规范，减少信息冗余。

### Modified Capabilities

（无）

## Impact

- Web：调整 `src/App.tsx` 导航结构；新增 Drawer 组件与图标；优化排行榜列表行展示；统一部分按钮/标题/副标题文案与样式。
- 依赖：不引入重型 UI 框架；图标使用内联 SVG（统一 24x24）。
